Realitätscheck zuerst

Ich baue dir etwas, das wirklich läuft — darum vier ehrliche Grenzen vorweg.

✓ Was dein Dell kann

Ein 7B-Modell in Q4-Quantisierung (~4,7 GB) auf der CPU: Skripte, strukturiertes JSON, Themenplanung, Quellenauswertung, Captions, Hashtags. Dazu FFmpeg-Rendering in 1080×1920. Pro Lauf entsteht ein komplettes Paket in ~5–12 Minuten.

✕ Was dein Dell nicht kann

Fotorealistische Bilder/Videos lokal generieren oder ein Avatar-Modell betreiben. Die Iris Xe teilt sich den RAM und hat keinen nutzbaren VRAM-Vorteil — bewusst CPU-only. Stock-Clips aus freien Quellen sind der richtige Weg.

⚠ „Autonom“ ≠ „ohne dich“

Auto-Upload für Instagram/Facebook/TikTok setzt Business-Konto + geprüfte Developer-App voraus; du hast Privatkonten. Also: volle Automation bis zum fertigen Paket, dann 1 Klick Freigabe und manueller Upload. Das ist markensicherer als ein API-Bann.

⚠ „Viel Geld“ braucht eine Brücke

Shorts-Ad-Umsatz ist klein. TikTok zahlt im Creator-Rewards-Programm nur für Videos über 1 Minute; YouTube verlangt 1.000 Abos + 4.000 Watch Hours (oder 10 Mio. Shorts-Views/90 Tage) — für Neuanmeldungen ab 01.02.2027 doppelt so hoch. Deshalb: 70-Sekunden-Videos plus Langform-Schiene plus Sponsoring. Details in Kapitel 10.

Kurz gesagt: Du bekommst eine Pipeline, die jeden Morgen ohne Zutun ein fertiges Paket ablegt: video.mp4, captions.srt, thumbnail.png, Titel, Beschreibung, Hashtags, X/Facebook-Post, Quellenliste und Upload-Checkliste. Was fehlt, ist nur dein Klick und der Upload. Kosten: 0 € laufend.

Grenzen akzeptiert, Erwartung kalibriert

Hake das ab, wenn du mit „Automation bis zur Freigabe, manueller Upload, Wachstum organisch, Geld über Langform + Sponsoring“ einverstanden bist. Alles Weitere baut darauf auf.

Warum ich das so deutlich sage

Ein Plan, der „vollautomatisch auf 5 Plattformen posten und viel Geld verdienen“ verspricht, scheitert an App-Reviews, Plattform-Regeln und an der Physik deiner CPU. Die ehrliche Version ist schneller umgesetzt und hält länger.

Warum Tailscale statt Portweiterleitung?

Deine Fritzbox/Router bleibt zu, Cloudflare muss nichts freigeben, und n8n-Oberfläche wie Worker sind nur für deine eigenen Geräte sichtbar. Die ufw-Regeln in Phase 1 binden zusätzlich alles an das Interface tailscale0.

def _clean(value: str) -> str:
    value = html.unescape(re.sub(r"<[^>]+>", " ", value or ""))
    return re.sub(r"\s+", " ", value).strip()


def rss_research(topic: str, lang: str = "en", limit: int = 7) -> list[dict]:
    """Google News RSS — kostenlos, ohne Key, ohne Registrierung."""
    hl, gl, ceid = (("en-US", "US", "US:en") if lang.startswith("en")
                    else ("de", "DE", "DE:de"))
    url = "https://news.google.com/rss/search?" + urllib.parse.urlencode(
        {"q": topic, "hl": hl, "gl": gl, "ceid": ceid}
    )
    try:
        resp = requests.get(url, headers=UA, timeout=20)
        resp.raise_for_status()
        feed = feedparser.parse(resp.content)
        return [
            {
                "title": _clean(e.get("title", "")),
                "url": e.get("link", ""),
                "summary": _clean(e.get("summary", ""))[:300],
                "source": "Google News RSS",
            }
            for e in feed.entries[:limit]
            if e.get("title")
        ]
    except Exception as exc:                                # nie die Pipeline killen
        print(f"[sources] RSS nicht erreichbar: {exc}")
        return []


def brave_research(topic: str, lang: str = "en", limit: int = 5) -> list[dict]:
    """Optional: Brave Search API, Free-Tier 2.000 Queries/Monat, 1 Query/Sekunde."""
    if not cfg.BRAVE_API_KEY:
        return []
    try:
        resp = requests.get(
            "https://api.search.brave.com/res/v1/web/search",
            params={"q": topic, "count": limit,
                    "search_lang": "en" if lang.startswith("en") else "de"},
            headers={**UA, "Accept": "application/json",
                     "X-Subscription-Token": cfg.BRAVE_API_KEY},
            timeout=20,
        )
        resp.raise_for_status()
        results = resp.json().get("web", {}).get("results", [])
        return [
            {"title": _clean(x.get("title", "")), "url": x.get("url", ""),
             "summary": _clean(x.get("description", "")), "source": "Brave"}
            for x in results if x.get("title")
        ]
    except Exception as exc:
        print(f"[sources] Brave nicht erreichbar: {exc}")
        return []


def research(topic: str, lang: str = "en") -> list[dict]:
    items, seen = [], set()
    for item in rss_research(topic, lang) + brave_research(topic, lang):
        key = item["title"].lower()
        if key not in seen:
            seen.add(key)
            items.append(item)
    return items[:8]


def fetch_clip(query: str, dest: Path, timeout: int = 90) -> Path | None:
    """Optional: passendes Pexels-Video im Hochformat. Ohne Key -> None."""
    if not cfg.PEXELS_API_KEY:
        return None
    try:
        resp = requests.get(
            "https://api.pexels.com/videos/search",
            params={"query": query[:80], "orientation": "portrait",
                    "per_page": 5, "size": "sd"},
            headers={**UA, "Authorization": cfg.PEXELS_API_KEY},
            timeout=20,
        )
        resp.raise_for_status()
        best = None
        for video in resp.json().get("videos", []):
            for f in video.get("video_files", []):
                width, height = f.get("width", 0), f.get("height", 0)
                if height >= width and width >= 540 and f.get("link"):
                    if best is None or width < best.get("width", 99999):
                        best = f
            if best:
                break
        if not best:
            return None
        dest.parent.mkdir(parents=True, exist_ok=True)
        with requests.get(best["link"], headers=UA, stream=True, timeout=timeout) as dl:
            dl.raise_for_status()
            with open(dest, "wb") as fh:
                for chunk in dl.iter_content(1 << 20):
                    if chunk:
                        fh.write(chunk)
        return dest if dest.stat().st_size > 50_000 else None
    except Exception as exc:
        print(f"[sources] Pexels nicht erreichbar: {exc}")
        return None

"""AuronOrigin | Text-to-Speech mit 3-Stufen-Fallback (0 EUR).

1. edge-tts  — kostenlos, natuerliche Stimmen, braucht Internet aber keinen Key
2. piper     — komplett offline, falls installiert + Modell in .env hinterlegt
3. espeak-ng — immer da (apt), robotisch, aber die Pipeline laeuft garantiert
"""
from __future__ import annotations

import settings as cfg


def probe(path: Path) -> float:
    try:
        out = subprocess.check_output(
            ["ffprobe", "-v", "error", "-show_entries", "format=duration",
             "-of", "default=nw=1:nk=1", str(path)],
            text=True, timeout=30,
        )
        return float(out.strip())
    except Exception:
        return 0.0


def _edge(text: str, voice: str, dest: Path) -> None:
    import edge_tts

    async def _go():
        communicate = edge_tts.Communicate(text, voice, rate="+5%")
        await communicate.save(str(dest))

    asyncio.run(_go())


def _piper(text: str, lang: str, wav: Path) -> bool:
    model = cfg.PIPER_MODEL_EN if lang.startswith("en") else cfg.PIPER_MODEL_DE
    if not model or not shutil.which("piper") or not Path(model).exists():
        return False
    subprocess.run(["piper", "--model", model, "--output_file", str(wav)],
                   input=text.encode("utf-8"), check=True, timeout=180)
    return wav.exists()


def _espeak(text: str, lang: str, wav: Path) -> None:
    voice = "en-us" if lang.startswith("en") else "de"
    subprocess.run(["espeak-ng", "-v", voice, "-s", "150", "-w", str(wav)],
                   input=text.encode("utf-8"), check=True, timeout=180)


def synth(text: str, dest_mp3: Path, lang: str = "en") -> tuple[Path, float]:
    """Gibt (mp3-Pfad, Dauer in Sekunden) zurueck."""
    dest_mp3 = Path(dest_mp3)
    dest_mp3.parent.mkdir(parents=True, exist_ok=True)
    wav = dest_mp3.with_suffix(".wav")
    voice = cfg.TTS_VOICE_EN if lang.startswith("en") else cfg.TTS_VOICE_DE

    if cfg.TTS_ENGINE in ("edge", "auto"):
        try:
            _edge(text, voice, dest_mp3)
            duration = probe(dest_mp3)
            if duration > 0.5:
                return dest_mp3, duration
        except Exception as exc:
            print(f"[voice] edge-tts: {exc} -> Fallback")

    try:
        if _piper(text, lang, wav):
            subprocess.run(["ffmpeg", "-y", "-loglevel", "error", "-i", str(wav),
                            "-ar", "44100", "-ac", "2", "-b:a", "128k", str(dest_mp3)],
                           check=True, timeout=120)
            duration = probe(dest_mp3)
            if duration > 0.5:
                return dest_mp3, duration
    except Exception as exc:
        print(f"[voice] piper: {exc} -> Fallback")

    _espeak(text, lang, wav)
    subprocess.run(["ffmpeg", "-y", "-loglevel", "error", "-i", str(wav),
                    "-ar", "44100", "-ac", "2", "-b:a", "128k", str(dest_mp3)],
                   check=True, timeout=120)
    return dest_mp3, max(probe(dest_mp3), 1.0)

"""AuronOrigin | FFmpeg-Renderer (reine CPU, Iris Xe wird NICHT benoetigt).

def _run(cmd: list[str], timeout: int = 600) -> subprocess.CompletedProcess:
    try:
        return subprocess.run(cmd, check=True, text=True, capture_output=True, timeout=timeout)
    except subprocess.CalledProcessError as exc:
        raise RuntimeError(f"FFmpeg-Fehler:\n{' '.join(cmd)}\n{exc.stderr[-1200:]}") from exc


def wrap(text: str, width: int = 30) -> str:
    return "\n".join(textwrap.wrap(text or "", width=width, break_long_words=False))


def make_card(headline: str, path: Path, index: int = 0) -> Path:
    """Titelkarte ohne jede externe Bildquelle — funktioniert immer offline."""
    W, H = cfg.W, cfg.H
    grad = Image.new("RGB", (1, H))
    top, bottom = (9, 13, 30), (23, 43, 73)
    for y in range(H):
        t = y / H
        grad.putpixel((0, y), tuple(int(top[i] + (bottom[i] - top[i]) * t) for i in range(3)))
    img = grad.resize((W, H))
    draw = ImageDraw.Draw(img)
    accent = (53, 224, 200) if index % 2 == 0 else (139, 124, 255)
    draw.ellipse([int(W * 0.18), int(H * 0.20), int(W * 0.82), int(H * 0.62)],
                 outline=accent, width=9)
    draw.ellipse([int(W * 0.30), int(H * 0.28), int(W * 0.70), int(H * 0.54)],
                 outline=accent, width=3)
    try:
        font = ImageFont.truetype(cfg.FONT_BOLD, 76)
        small = ImageFont.truetype(cfg.FONT_REGULAR, 38)
    except OSError:
        font = small = ImageFont.load_default()
    draw.text((W // 2, int(H * 0.10)), "AURONORIGIN", font=small,
              fill=(160, 180, 210), anchor="mm")
    lines = wrap(headline, 22).split("\n")[:5]
    y = int(H * 0.70)
    for line in lines:
        draw.text((W // 2, int(y)), line, font=font, fill=(255, 255, 255), anchor="mm")
        y += 100
    draw.rectangle([int(W * 0.30), int(H * 0.90), int(W * 0.70), int(H * 0.905)],
                   fill=accent)
    path.parent.mkdir(parents=True, exist_ok=True)
    img.save(path)
    return path


def render_scene(index: int, scene: dict, voice_mp3: Path, visual: Path,
                 work: Path, duration: float) -> Path:
    W, H, FPS = cfg.W, cfg.H, cfg.FPS
    caption_file = work / f"caption_{index:02d}.txt"
    # drawtext expandiert %-Sequenzen: Prozentzeichen doppeln
    caption_file.write_text(
        wrap(scene.get("caption", ""), 30).replace("%", "%%"), encoding="utf-8")
    out = work / f"scene_{index:02d}.mp4"

    box_y, box_h = int(H * 0.72), int(H * 0.22)
    vf = (
        f"scale={W}:{H}:force_original_aspect_ratio=increase,crop={W}:{H},setsar=1,"
        f"fps={FPS},format=yuv420p,"
        f"drawbox=x=0:y={box_y}:w={W}:h={box_h}:color=black@0.55:t=fill,"
        f"drawtext=fontfile={cfg.FONT_BOLD}:textfile={caption_file}:"
        f"fontcolor=white:fontsize=52:line_spacing=14:"
        f"x=(w-text_w)/2:y={box_y + 40}:borderw=1:bordercolor=black@0.6"
    )

    cmd = ["ffmpeg", "-y", "-loglevel", "error"]
    if visual.suffix.lower() in (".mp4", ".mov", ".webm", ".mkv"):
        cmd += ["-stream_loop", "-1", "-i", str(visual)]
    else:
        cmd += ["-loop", "1", "-framerate", str(FPS), "-i", str(visual)]
    cmd += [
        "-i", str(voice_mp3), "-t", f"{duration:.3f}",
        "-vf", vf,
        "-c:v", "libx264", "-preset", "veryfast", "-crf", "23", "-r", str(FPS),
        "-pix_fmt", "yuv420p", "-c:a", "aac", "-b:a", "128k", "-ar", "44100", "-ac", "2",
        "-shortest", "-movflags", "+faststart", str(out),
    ]
    _run(cmd)
    return out


def concat(scene_files: list[Path], work: Path) -> Path:
    listing = work / "concat.txt"
    listing.write_text("\n".join(f"file '{p.as_posix()}'" for p in scene_files) + "\n",
                       encoding="utf-8")
    joined = work / "joined.mp4"
    _run(["ffmpeg", "-y", "-loglevel", "error", "-f", "concat", "-safe", "0",
          "-i", str(listing), "-c", "copy", str(joined)])
    return joined

def _timestamp(seconds: float) -> str:
    ms = int(seconds * 1000)
    h, ms = divmod(ms, 3_600_000)
    m, ms = divmod(ms, 60_000)
    s, ms = divmod(ms, 1000)
    return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"


def write_srt(scenes: list[dict], durations: list[float], path: Path) -> Path:
    start, lines = 0.0, []
    for i, (scene, dur) in enumerate(zip(scenes, durations), 1):
        lines.append(f"{i}\n{_timestamp(start)} --> {_timestamp(start + dur)}\n"
                     f"{scene.get('caption', '')}\n")
        start += dur
    path.write_text("\n".join(lines), encoding="utf-8")
    return path

def _parse_json(raw: str) -> dict | None:
    cleaned = re.sub(r"^```(?:json)?|```$", "", raw.strip(), flags=re.M).strip()
    start, end = cleaned.find("{"), cleaned.rfind("}")
    if start < 0 or end <= start:
        return None
    try:
        return json.loads(cleaned[start:end + 1])
    except json.JSONDecodeError:
        return None


def _validate(data: dict, topic: str) -> dict:

            "visual_query": str(sc.get("visual_query") or topic)[:80],
        })

    return {
        "title": str(data.get("title") or topic)[:70],
        "hook": str(data.get("hook") or clean[0]["narration"])[:200],
        "thumbnail_text": str(data.get("thumbnail_text") or topic)[:40],
        "scenes": clean,
        "description": str(data.get("description") or "")[:1200],
        "hashtags": [str(h) for h in (data.get("hashtags") or []) if str(h).startswith("#")][:12],

        data = _parse_json(_ollama(messages)) or _parse_json(
            _ollama(messages + [{"role": "user", "content": "Return ONLY the JSON object now."}]))
        if data:
            return _validate(data, topic), False
    except Exception as exc:
        print(f"[pipeline] Ollama nicht verfuegbar: {exc}")
    return _fallback_script(topic, lang), True


def next_topic() -> str:
    topics_file = Path(__file__).with_name("topics.json")
    topics = json.loads(topics_file.read_text(encoding="utf-8"))
    state = cfg.CACHE / "topic_state.json"
    idx = 0
    if state.exists():
        try:
            idx = int(json.loads(state.read_text(encoding="utf-8")).get("index", 0))
        except Exception:
            idx = 0
    item = topics[idx % len(topics)]
    state.write_text(json.dumps({"index": idx + 1}), encoding="utf-8")
    return item["topic"] if isinstance(item, dict) else str(item)


def _slug(topic: str) -> str:
    clean = re.sub(r"[^a-z0-9]+", "-", topic.lower()).strip("-")[:42]
    return dt.datetime.now().strftime("%Y%m%d-%H%M") + "-" + (clean or "video")

def run(topic: str | None = None, lang: str | None = None) -> dict:
    lang = (lang or cfg.CONTENT_LANG).lower()
    topic = topic or next_topic()
    started = time.time()
    slug = _slug(topic)
    work = cfg.CACHE / slug
    pkg = cfg.DRAFTS / slug
    if work.exists():
        shutil.rmtree(work)
    work.mkdir(parents=True)
    pkg.mkdir(parents=True, exist_ok=True)

    used_sources = sources.research(topic, lang)
    content, degraded = build_script(topic, used_sources, lang)
    scenes = content["scenes"][:8]

    scene_files, durations = [], []
    for i, scene in enumerate(scenes):
        mp3 = work / f"voice_{i:02d}.mp3"
        _, dur = voice.synth(scene["narration"], mp3, lang)
        dur = max(dur, 2.0)
        clip = sources.fetch_clip(scene["visual_query"], work / f"clip_{i:02d}.mp4")
        visual = clip or render.make_card(scene["caption"], work / f"card_{i:02d}.png", i)
        scene_files.append(render.render_scene(i, scene, mp3, visual, work, dur))
        durations.append(dur)

    joined = render.concat(scene_files, work)
    final = pkg / "video.mp4"
    render.finalize(joined, final)
    render.thumbnail(final, pkg / "thumbnail.png")
    render.write_srt(scenes, durations, pkg / "captions.srt")
    seconds = render.duration(final)
    _write_texts(pkg, content, lang, used_sources, seconds, degraded)

    shutil.rmtree(work, ignore_errors=True)
    return {
        "slug": slug, "title": content["title"], "lang": lang,
        "duration_seconds": round(seconds, 1), "scenes": len(scenes),
        "sources": len(used_sources), "degraded": degraded,
        "elapsed_seconds": round(time.time() - started, 1),
        "path": str(pkg),
        "review_url": "/review",
        "note": ("Ollama war nicht erreichbar -> Notfall-Skript verwendet."
                 if degraded else "Bereit zur Freigabe."),
    }


def list_drafts() -> list[dict]:
    out = []
    for folder in sorted(cfg.DRAFTS.iterdir(), reverse=True):
        manifest = folder / "manifest.json"
        if folder.is_dir() and manifest.exists():
            try:
                data = json.loads(manifest.read_text(encoding="utf-8"))
                data["slug"] = folder.name
                data["video_url"] = f"/out/ENTWURF/{folder.name}/video.mp4"
                out.append(data)
            except Exception:
                continue
    return out


def approve(slug: str) -> dict:
    src, dst = cfg.DRAFTS / slug, cfg.APPROVED / slug
    if not src.exists():
        raise FileNotFoundError(f"Kein Entwurf: {slug}")
    dst.parent.mkdir(parents=True, exist_ok=True)
    if dst.exists():
        shutil.rmtree(dst)
    shutil.move(str(src), str(dst))
    manifest_file = dst / "manifest.json"
    data = json.loads(manifest_file.read_text(encoding="utf-8"))
    data["status"] = "FREIGEGEBEN"
    data["approved_at"] = dt.datetime.now().isoformat(timespec="seconds")
    manifest_file.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")
    (dst / "FREIGABE.txt").write_text(
        "Freigegeben — jetzt manuell hochladen. Siehe UPLOAD.md in diesem Ordner.\n"
        + data.get("caption", "") + "\n", encoding="utf-8")
    return {"slug": slug, "status": "FREIGEGEBEN", "path": str(dst),
            "caption": data.get("caption", ""), "post_text": data.get("post_text", "")}


def discard(slug: str) -> dict:
    src, dst = cfg.DRAFTS / slug, cfg.REJECTED / slug
    if not src.exists():
        raise FileNotFoundError(f"Kein Entwurf: {slug}")
    dst.parent.mkdir(parents=True, exist_ok=True)
    shutil.move(str(src), str(dst))
    return {"slug": slug, "status": "VERWORFEN"}


def plan_week(lang: str | None = None) -> dict:
    """Montags: 7 Themen + Hooks vom schnellen 3B-Modell, ohne Video zu rendern."""
    lang = (lang or cfg.CONTENT_LANG).lower()
    language = "German" if lang.startswith("de") else "English"
    prompt = (
        f"You are the content planner for AuronOrigin (AI, automation, digital systems "
        f"for solo entrepreneurs). Return ONLY a JSON object with key 'ideas': an array "
        f"of exactly 7 objects with keys 'topic', 'hook', 'pillar'. Topics must be "
        f"evergreen, specific, non-hype, in {language}. No markdown."
    )
    try:
        raw = _ollama([{"role": "user", "content": prompt}],
                      model=cfg.OLLAMA_FAST_MODEL, timeout=240)
        data = _parse_json(raw) or {}
        ideas = data.get("ideas", [])[:7]
    except Exception as exc:
        print(f"[pipeline] Wochenplan: {exc}")
        ideas = []
    if len(ideas) < 7:
        ideas = [{"topic": next_topic(), "hook": "Was davon ist wirklich neu?",
                  "pillar": "Systeme"} for _ in range(7)]
    week = dt.date.today().strftime("%G-KW%V")
    path = cfg.PLANS / f"wochenplan-{week}-{lang}.md"
    lines = [f"# AuronOrigin | Wochenplan {week} ({lang})", ""]
    for i, idea in enumerate(ideas, 1):
        lines += [f"## Tag {i}: {idea.get('topic', '')}",
                  f"- Hook: {idea.get('hook', '')}",
                  f"- Säule: {idea.get('pillar', '')}", ""]
    path.write_text("\n".join(lines), encoding="utf-8")
    return {"path": str(path), "ideas": len(ideas), "week": week}

Recht & KI-Kennzeichnung

Seit 02.08.2026 ist das kein „nice to have“ mehr. Bitte einmal bewusst durchgehen.

EU AI Act, Artikel 50

Die Transparenzpflichten für Anbieter und Betreiber generativer KI gelten seit dem 2. August 2026: maschinenlesbare Kennzeichnung von KI-Outputs und sichtbare Offenlegung bei Deepfakes bzw. KI-erzeugten Inhalten. Die EU-Kommission hat dazu einen Code of Practice veröffentlicht. Für dich als Veröffentlicher heißt das praktisch: immer kennzeichnen, wenn etwas realistisch wirkt. Keine Rechtsberatung — im Zweifel anwaltlich prüfen.

Reine Skript-Hilfe oder offensichtlich stilisierte Grafiken lösen die Pflicht in der Regel nicht aus — eine realistisch klingende KI-Stimme über realistischem Bildmaterial aber schon. Die Labels senken laut Plattformangaben die Reichweite nicht. Quellen siehe Kapitel 15.
